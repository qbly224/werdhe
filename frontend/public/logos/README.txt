Logos des opérateurs de paiement mobile
=======================================

Déposez ici les logos officiels (aucun logo n'est fourni par défaut) :

  orange-money.svg   (ou orange-money.png)
  mtn-momo.svg       (ou mtn-momo.png)

Format carré conseillé (au moins 96 x 96 px pour un PNG). Le site essaie d'abord le .svg puis le .png.
Tant qu'un fichier est absent, un carré de couleur avec les initiales est affiché à sa place
(composant frontend/src/components/paiement-mobile/OperateurLogo.js).
